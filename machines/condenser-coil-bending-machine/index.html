Condenser Coil Bending Machine

A finished condenser core has to become an L or a U without crushing the fins or closing the tube ends. This machine bends the core with a servo driven roller, angle set 0 to 120 degrees on the HMI, in a cycle of no more than 14 seconds. One, two or three layer cores are handled by setting the bending thickness, and core thinning stays under 5 percent, which is the number that decides whether the coil still passes its pressure and performance test.

Key Advantages

Why bending is the step that decides whether a coil ships.

L and U from one machine

Both shapes are set on the HMI, so a mixed order does not need two machines or a manual press brake.

Thinning held under 5%

The roller spreads the load across the core face. A crushed bend shows up later as a failed leak or performance test, not at the machine.

14 seconds, including handling

Short enough that the bender keeps pace with the assembly line it sits on.

One to three layers

Layer count and bending thickness are set per coil, so a thicker core is not bent with the same programme as a thin one.

Automatic or manual

Production runs in automatic; a new core is set up in manual and saved as a recipe.

Frequently Asked Questions

Questions buyers ask before a core bender is ordered.

Which shapes can it make?

L and U, with the bending angle set from 0 to 120 degrees on the HMI and a minimum short edge of 50 mm on an L bend.

Will it crush the fins?

Core thinning stays under 5 percent, because the roller spreads the load over the full core face and the angle is servo positioned rather than pressed by hand.

Can it bend multi-layer cores?

Yes, one, two or three layer cores, with 13.37 mm, 19.05 mm or 22 mm bending thickness selected to match.

How fast is a bend?

No more than 14 seconds per bend, excluding loading and unloading.

Is it manual or automatic?

Both. Production runs automatically; setting up a new core is done in manual mode and saved as a recipe.
